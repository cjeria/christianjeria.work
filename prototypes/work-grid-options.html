Work Grid — 3 Layout Options

Option A

Responsive Grid

3 columns on desktop, 2 on tablet, 1 on mobile. Uniform cards with a top thumbnail and body below. Clean, predictable, easy to scan — the standard portfolio pattern.

Option B

Editorial List

Full-width horizontal rows — large thumbnail on the left (380px), rich text content on the right. One project per row. More immersive, shows context well. Stacks vertically on mobile.

Option C

Bento Grid

Asymmetric 4-column grid with featured projects spanning 2 columns × 2 rows. Size creates hierarchy — featured work gets more visual weight. Text overlays the thumbnail directly.
